# Doctor Appointment Booking – Frontend

React frontend for a doctor appointment booking platform: find doctors, view profiles and reviews, book appointments, and manage everything from patient and doctor dashboards.

**Live demo:** https://doctor-appointment-xi-kohl.vercel.app

**API:** [Doctor-Appointment-Project-Backend](https://github.com/xeetriaman/Doctor-Appointment-Project-Backend)

## Tech stack
React 18, Vite, React Router, Tailwind CSS, React Toastify, Swiper

## Features
- Home, services, doctors list and doctor detail pages
- Sign up and log in with JWT auth
- Patient dashboard (my appointments, profile) and doctor dashboard
- Reviews and ratings

## Run locally
```bash
npm install
cp .env.example .env   # VITE_API_URL points at the API
npm run dev
```
